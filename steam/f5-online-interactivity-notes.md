# F5 — Online Interactivity flag

Valve F5: the Content Survey indicated **Online Interactivity**, but the reviewer
couldn't find it in the build. Steam defines "online interactivity" as games with online
modes where **players directly interact with each other** (real-time multiplayer,
in-game chat between players, shared/co-op sessions).

Dashboard Engine has **none** of that. It is a single-user desktop wallpaper app. Its
only networked/community feature is **Steam Workshop — asynchronous content sharing**
through Valve's own UGC system (a user publishes a pack or voice profile; others
subscribe and download it later). There is no real-time player-to-player interaction, no
chat between players, no shared or multiplayer sessions.

**Action: the Online Interactivity flag has been UNCHECKED in the Content Survey (done),
so the survey matches the build.**
